# Figure, script and data map

`python scripts/make_figures.py` redraws every figure from the archived data. The table also lists the scripts that generated the data
(see `scripts/run_all_experiments.sh` for the full recomputation in execution order).

|---|---|---|---|---|
| 1 | `Fig01_schematic` | `n2_schematic.py` | numbers of Fig. 2 | - |
| 2 | `Fig02_anatomy` | `n1_figures.py anatomy` | `N1/bethe_N24_b2.5_s2_anatomy.*` | `n1_levels.py anatomy` (via `n1_run_all.sh`) |
| 3 | `Fig03_partial` | `n2_figures.py partial` | `N3/partial_N24.npz`, `N2/paths_*` | `n3_partial.py`, `n2_paths.py` (via `n2_run.sh`) |

Shared helper modules in `experiments/`: `e3b_e1_heldout_hierarchy.py`, `e4de_independent_heatbath.py`, `e4dg_numba_kernel.py`,
`e5_largeN_importance.py`, `e6_common.py`, `s7_e7_static_dynamic.py`.

Naming of the result folders follows the order in which the campaigns were run: `E0` positive control; `E5B`-`E5F` sampled posteriors
and controls at N = 32, 64 and the exact N = 16 cohort; `E6` contrast identities and learned denoisers; `S7` label-free spectral prediction; `S8` validation;
`N1`-`N4` the exact campaign of the main text (`N1`/`N1S` classes and decision times, `N2` per-trajectory commitments and discretization,
`N3` class posteriors of the N = 24 instance, `N4` Bethe vs SK summary).
